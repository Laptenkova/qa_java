# qa_java

<h2>QA Java Project</h2>

<h3>Описание проекта</h3>
Проект содержит юнит-тесты для программы, которую используют зоологи для работы с семейством кошачьих.
Реализованы тесты для классов:

* Feline - базовый класс
* Cat
* Lion (использует внедрение зависимостей через инъекцию)

Достигнуто 100% покрытие:

* Для каждого метода каждого класса написан отдельный тест
* Для всех веток условий написаны отдельные тесты
* Реализованы параметризованные тесты для различных сценариев

<h3>Технологии</h3>

* Язык программирования: Java 11
* Фреймворк для тестирования: JUnit 4.13.2
* Инструменты для мокирования: Mockito 5.19.0
* Покрытие тестами: JaCoCo 0.8.13
* Сборка проекта: Maven 3.8.1

<h3>Структура проекта</h3>
`src/main/java` — основные классы приложения: Feline, Cat, Lion <br>
`src/test/java` — юнит-тесты, включая параметризованные и тесты с моками

<h3>Настройка проекта</h3>

* Установите Java 11
* Установите Maven версии 3.9.0
* Клонируйте репозиторий: `git clone <repository-url>`

<h3>Запуск тестов</h3>
Выполните команду: `mvn clean test`

<h3>Генерация отчета покрытия</h3>
Выполните команду: `mvn jacoco:report` <br>
Oтчет будет доступен в: `target/site/jacoco/index.html`

<h3>Особенности реализации</h3>

1. Инъекция зависимостей - класс Lion не зависит напрямую от Feline
2. Мок-объекты — изоляция тестируемых компонентов с помощью @Mock
3. Параметризованные тесты — для покрытия различных сценариев и граничных условий
4. Отдельные классы для параметризации
5. 100% покрытие тестами классов Feline, Cat, Lion
6. Отчёт Jacoco — для мониторинга покрытия кода

<h3>Известные проблемы</h3>

* Некоторые методы или ветки требуют отдельной логики для создания параметризированных тестов.
* Jacoco-отчёт может быть не сразу доступен, если папка target добавлена в .gitignore.
